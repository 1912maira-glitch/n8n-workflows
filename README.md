# ⚡ n8n Automation Workflows

A collection of **n8n automation workflows** created while learning and practicing workflow automation, AI integrations, APIs, data processing, and business process automation.

This repository contains practical projects ranging from **AI-powered assistants and RAG chatbots to lead generation, customer feedback automation, KPI analysis, content generation, and business workflows**.

## 📂 Projects

| Project | Description |
|---|---|
| 🤝 **Client Onboarding** | Automates the client onboarding process using structured workflow steps and integrations. |
| 💻 **Code Summarizer & Comment Generator** | Uses AI to analyze source code and generate summaries/comments to improve code understanding and documentation. |
| 💬 **Customer Feedback & Discount** | Processes customer feedback and automates follow-up/discount-related actions. |
| 📊 **KPI Analysis** | Processes business KPI data and uses automation/AI for analysis and reporting. |
| 📱 **Leads Generation – Instagram** | Automates parts of the lead generation process using Instagram-related data and workflow automation. |
| 📅 **Meeting Management System** | Automates meeting-related tasks such as processing meeting information and managing follow-up actions. |
| 🤖 **Personal Assistant Workflow** | An AI-powered assistant workflow designed to automate common personal/productivity tasks. |
| 🧠 **RAG Chatbot** | Retrieval-Augmented Generation workflow that combines retrieved information with an LLM to generate contextual responses. |
| 🎥 **Video Generation** | Experiments with automating AI-assisted video generation workflows. |
| 🏢 **AI Sales & Service Brain** | Business automation system focused on inquiries, quotations, complaints, leads, reporting, and AI-powered sales/service processes. |
